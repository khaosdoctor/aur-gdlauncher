# aur-gdlauncher

Source for the [gdlauncher-carbon-bin](https://aur.archlinux.org/packages/gdlauncher-carbon-bin) AUR package.

A daily workflow checks the GDLauncher update feed, bumps `PKGBUILD` when a new version is out, and publishes it to the AUR. Pushing a `PKGBUILD` change to `master` also publishes it.
